🚀 How to Run

1. Open the folder containing the question you want to run.

2. Open its JavaScript file and check which HTML file it belongs to.

3. Connect the JavaScript file to the corresponding HTML file using a "<script>" tag:
   
   <script src="script.js" defer></script>
   
   Replace "script.js" with the actual JavaScript filename and adjust the path if the file is in another folder.

4. Open the HTML file in your browser to run the solution.

5. Open the browser's Developer Tools console to view output or errors, if applicable.

«Note: Some solutions may require specific HTML elements or user interactions. Make sure the required HTML structure is present before running the JavaScript.»
